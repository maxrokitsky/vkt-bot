# vkt-ai

ИИ-агент в чате: `/ai <вопрос>`. Отвечает текстом или сходит инструментами
за ролями, составом чата, журналом событий и историей переписки.

Провайдер — любой OpenAI-совместимый шлюз; по умолчанию OpenRouter.
Настройки — с префиксом `AI_` в `.env`, выключатель на ходу —
`ai_enabled` в `bot_settings`.
