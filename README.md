# vkt-bot

WORK IN PROGRESS!!!

Бот для VK Teams предоставляющий инструменты для удобства использования мессенджера и интеграции с другими системами.

## Структура проекта
- **vkt-bot**: само приложение 
- **vkt-dispatcher:** фреймворк, управляющий жизненым циклом бота и позволяющий устаналивать хэндлеры на события
- **vkteams-client:** асинхронный клиент для VK Teams Bot Api 

### Плагины
- **vkt-gitlab**: интеграция с GitLab (плагин)
