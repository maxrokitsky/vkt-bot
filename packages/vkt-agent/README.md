# vkt-agent

Каркас ИИ-агента: зависимости инструментов (`AgentDeps`), реестр
инструментов с метаданными, политика подтверждений и запуск сессии с
лимитами.

Пакет не импортирует `vkt_bot` — как и `vkt-dispatcher`, он тестируется
отдельно. Всё, что знает о базе и о боте, приезжает через `AgentDeps`.
