# VKT Bot Control Panel

Панель управления для VKT Bot - современное SPA-приложение для управления ботом VK Teams.

## Возможности

- Авторизация пользователей с JWT
- Управление пользователями (только для администраторов)
  - Создание, редактирование, удаление пользователей
  - Управление статусами и правами
  - Пагинация списка пользователей
- Просмотр чатов
  - Список всех чатов с пагинацией
  - Поиск по названию чата
- Управление ролями
  - Создание, редактирование, удаление ролей
  - Управление участниками ролей
  - Добавление и удаление пользователей из ролей
- Адаптивный интерфейс с использованием Tailwind CSS v4
- Современные UI компоненты shadcn-vue

## Технологический стек

- **Vue 3** - прогрессивный JavaScript фреймворк
- **TypeScript** - типизированный JavaScript
- **Vue Router** - маршрутизация
- **Pinia** - управление состоянием
- **TanStack Vue Query** - работа с API и кэширование
- **Tailwind CSS v4** - utility-first CSS фреймворк
- **shadcn-vue** - переиспользуемые компоненты UI
- **Hey API** - генерация типизированного клиента из OpenAPI
- **Vite** - сборщик и dev-сервер

## Установка

```bash
# Установка зависимостей
pnpm install

# Запуск dev-сервера
pnpm dev

# Сборка для production
pnpm build

# Предпросмотр production-сборки
pnpm preview
```

## Конфигурация

API клиент настраивается в файле `src/hey-api.ts`. По умолчанию используется:

```typescript
baseUrl: 'http://localhost:8000'
```

Измените этот URL на адрес вашего API сервера.

## Функциональность

### Авторизация

- Неавторизованные пользователи имеют доступ только к странице входа
- После успешной авторизации токен сохраняется в localStorage
- Автоматическое добавление Bearer токена ко всем API запросам

### Роли пользователей

- **Обычный пользователь**: доступ к чатам и ролям
- **Администратор**: полный доступ, включая управление пользователями

### Защищенные маршруты

- `/login` - доступна только неавторизованным
- `/users` - только для администраторов
- `/chats`, `/roles`, `/roles/:id/members` - для всех авторизованных пользователей
